Getting started

Install Kelp, open a repository and make your first commit. It takes about five minutes.

Install

Kelp runs on macOS 12 or later. Install it with Homebrew:

$ brew install hobo-ware/tap/kelp

This puts Kelp.app in your Applications folder and the kelp command on your PATH. Kelp checks for new releases and installs them in the background; when one is ready you'll see a restart button. You can turn that off in Settings.

You need git installed. Kelp uses your own git for everything that changes a repository, so your hooks, signing and config work as usual.

Open a repository

The first time Kelp starts, it shows the new tab page. From there you can:

  • Open folder (Cmd+O) to pick a repository on your Mac.
  • Clone to paste a URL and download a repository. Kelp opens it when the clone is done.
  • New repository to create an empty one.

You can also drop a folder onto the window. Every repository opens in its own tab, and Kelp reopens your tabs the next time it starts. Cmd+T opens a new tab with your recent repositories.

From the terminal

$ kelp ~/code/my-repo     # opens in the background, your prompt comes right back
$ kelp .                  # already running? the folder opens as a tab there
$ kelp -w ~/code/my-repo  # stay in the foreground until Kelp quits

If the folder is already open, Kelp switches to its tab. kelp --help lists the options.

Reading the graph

The middle of the window is the commit graph, newest commits at the top.

  • Each branch gets its own colored lane. Where two lanes join, a branch was merged.
  • Labels on a row show the branches and tags that point at that commit. The one with a check mark is the branch you have checked out. A +N chip means there are more; click it to see them all.
  • Click a commit to see its message, author and changed files in the details panel on the right. Click a file to see its diff.
  • Hover a commit to trace its branch. Right-click it for actions like cherry-pick, revert, reset or creating a branch there.
  • The sidebar on the left lists your branches, remotes, tags, stashes and worktrees. Double-click a branch to check it out.

Use Cmd+F to search commits and Cmd+Shift+F to filter by author, path or date. Cmd+K opens the command palette, which finds any action, branch, commit, file or tab.

Staging

When you have changes, a row called Uncommitted changes sits at the top of the graph (Cmd+Shift+C jumps there). Select it to open the staging panel, which has two lists: files you changed but have not staged, and files that are staged for the next commit.

  • Click a file to see its diff. Use the Stage and Unstage buttons on a file, or Stage all, to move whole files.
  • In the diff, stage or unstage a single hunk with its button, or select lines to stage only those.
  • Cmd-click or Shift-click files to pick several and stage, stash or discard them together.
  • Discarding asks first, and Cmd+Z brings the changes back.

Committing

Type a message in the commit box under the staged files and press Cmd+Enter. The first line is the title; leave a blank line before a longer description.

  • Tick Amend previous commit to change the last commit. Its message is filled in for you.
  • Cmd+Shift+Enter commits and pushes in one go.
  • The commit box can add a Conventional Commit type and co-authors from people in your history.
  • Made a mistake? Cmd+Z undoes the commit and keeps your changes. See what undo covers.

Push and pull from the toolbar, or with Cmd+Shift+U and Cmd+Shift+L. A branch without an upstream gets one on its first push.
